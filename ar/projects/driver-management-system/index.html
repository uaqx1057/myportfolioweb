DMS: نظام إدارة السائقين وتطبيق السائق على أندرويد

DMS، منصة Laravel وتطبيق سائق على أندرويد بتقنية Flutter صممتهما وطورتهما لإدارة العمليات اللوجستية اليومية، من السائقين والأسطول إلى الرواتب والحضور والتواصل.

هذه نظرة عامة على النظام. الشاشات الأصلية والبيانات والوصول المباشر إلى النظام غير متاحة هنا.

المشكلة

تدير عمليات التوصيل للميل الأخير عدداً كبيراً من السائقين عبر عدة منصات توصيل. كانت التكليفات والمركبات والحضور والرواتب المرتبطة بالأداء والخصومات والتواصل موزعة بين جداول البيانات ومجموعات المراسلة، مما جعل إعداد الرواتب بطيئاً وتتبع الأخطاء صعباً.

دوري

صممت نظام DMS وطورته: منصة الويب بتقنية Laravel وواجهتها البرمجية REST وتطبيق أندرويد بتقنية Flutter الذي يستخدمه السائقون يومياً. توليت البنية المعمارية وتصميم قاعدة البيانات والواجهة الخلفية وواجهة الإدارة وتطبيق الموبايل وإعداد الخوادم والإصدارات.

منصة الويب

  • السائقون والموارد البشرية: الملفات الشخصية والمستندات والعقود والحسابات البنكية والسكن وقضايا نقل الكفالة.
  • الأسطول: سجل تكليف المركبات والفحوصات مع أدلة مصورة وأوامر الصيانة والموردين وعقود التأجير وتتبع عداد المسافة والأضرار.
  • محرك الرواتب: ملفات قواعد قابلة للإعداد وشرائح وسيناريوهات أهداف لكل منصة، ودفعات رواتب، وقسائم رواتب مع سجل تدقيق، وقواعد خصم تشمل خصومات الحوادث.
  • العمليات: استيراد التقارير اليومية للمنسقين والمشرفين، ومطابقة فواتير الإيرادات، وطلبات الوقود وإعادة الشحن مع مسارات موافقة، والطلبات المالية.
  • الحضور والالتزام: المناوبات وتسجيل الحضور ضمن نطاق جغرافي ومراقبة النبض واكتشاف الحالات الشاذة والتحقق من الالتزام بالزي.
  • إدارة الامتيازات للمركبات والسائقين ومعرفات المنصات.
  • الأمان: صلاحيات حسب الدور والوحدة، وسجل تدقيق ووصول كامل مع تاريخ التغييرات على مستوى الحقول وفحوصات السلامة.

تطبيق السائق على أندرويد

  • تسجيل دخول آمن وملف السائق، مع واجهات بالعربية والإنجليزية.
  • تسجيل حضور المناوبة مع التحقق من الوجه وفحص الحيوية (منع الانتحال)، عبر خدمة Python مخصصة للتحقق من الوجه.
  • تتبع الموقع في الخلفية عبر خدمة أندرويد أمامية، مع قواعد استعادة من جهة الخادم.
  • قسائم الرواتب وتفاصيلها، والطلبات، وطلبات الوقود وإعادة الشحن.
  • محادثة ومكالمات صوتية داخل التطبيق (LiveKit مع شاشات مكالمات واردة أصلية)، وإشعارات فورية عبر Firebase Cloud Messaging.
  • تحديثات عبر الهواء باستخدام Shorebird وتقارير الأعطال عبر Firebase Crashlytics.

التقنيات

  • Laravel 11 و Livewire 3 وواجهة Laravel Sanctum البرمجية و MySQL و Redis
  • تطبيق أندرويد بتقنية Flutter/Dart: Firebase و LiveKit وتحديد الموقع والخدمات الخلفية
  • خدمة تحقق من الوجه بلغة Python و FastAPI مع DeepFace تعمل داخل Docker
  • إنشاء ملفات PDF (DomPDF و mPDF و FPDI)، واختبارات Pest و Dusk، ومهام مجدولة على خادم Linux افتراضي

حجم النظام

أكثر من 180 نموذج بيانات و360 ترحيلاً لقاعدة البيانات، وأكثر من 110 ملفات اختبار آلي، ونحو 50 مهمة مجدولة وأمر تشغيل، أُنجزت في نحو 900 عملية إيداع خلال عام واحد.
